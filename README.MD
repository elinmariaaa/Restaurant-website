# Taco 'Bout It 🌮

En smakrik webbplats för den mexikanska restaurangen **Taco 'Bout It**, byggd med kärlek till autentiska mexikanska smaker och modern webbutveckling.

## 📋 Om Projektet

Taco 'Bout It är en passionerad mexikansk restaurang som kombinerar traditionella recept med moderna tekniker. Webbplatsen visar upp vårt team, meny, bokningssystem och den unika taco-kultur vi levererar till våra gäster.

### 🎯 Funktioner

- **Huvudsidan**: Välkomstsektion med restaurangens historia och filosofi
- **Bokningssystem**: Interaktivt bordbokningssystem
- **Anställda**: Presentation av vårt passionerade team
- **Meny**: Komplett meny med autentiska mexikanska rätter
- **Team-portfolios**: Individuella presentationssidor för varje teammedlem
- **Responsiv design**: Optimerad för alla enheter

## 🚀 Komma Igång

### Förutsättningar

Ingen installation krävs! Detta är en statisk webbplats som fungerar direkt i webbläsaren.

### Installation och Körning

1. **Klona projektet**:
   ```bash
   git clone https://github.com/SimonSyntax/Emfira.git
   cd Emfira
   ```

2. **Öppna i webbläsare**:
   - Öppna `index.html` i din favoritwebbläsare
   - Eller använd en lokal server för bästa upplevelse!
     

3. **Navigera webbplatsen**:
   - Hem: `index.html`
   - Boka bord: `booking.html`
   - Anställda: `contacts.html`
   - Meny: `menu.html`
